A few minutes to launch

Run SwapLabs on your computer.

The local app uses a local SQLite database and local media storage. Nothing needs to be deployed to try the site.

The ZIP includes a README with detailed setup notes. Running pnpm start also rebuilds the download ZIP locally; the archive does not contain a copy of itself.

1

Download and unzip

Save the ZIP, then extract the SwapLabs folder somewhere you can write to.

2

Install the prerequisites

Use Node.js 20+, Python 3, and pnpm 10.4+. pnpm 11 needs Node.js 22 or newer.

3

Install and start

pnpm install --frozen-lockfile
pnpm start
4

Open the local site

Visit http://localhost:8000 in your browser and create a new local account.

5

Check the app

With SwapLabs running, open another terminal in the project folder and run pnpm check.

Good to know

A few practical details.

What is SwapLabs?

SwapLabs is a student-built skill-exchange platform. People can share what they know, learn from one another, find a match, and build a learning routine around time and practical skills.

Does the local app need an account?

You can browse the site locally. Create a new local account to explore account-based features; public member data is not preloaded.

Which features need external setup?

Email delivery and Google sign-in are not configured in the local copy. Live calls between separate networks may need a TURN relay. The included README describes the local setup.

Why is the ZIP not inside itself?

The archive cannot contain a full copy of itself. After you extract it, pnpm start builds a fresh public-source ZIP on your computer, so the download button works from the locally running site.

What is RelaySkills?

RelaySkills.com is a thriving peer-learning community built around people, skills, and shared spaces: people search, connect, practise together, and keep learning. The ZIP includes a separate RelaySkills community overview. SwapLabs is independent and is not affiliated with RelaySkills.

Where are the original credits?

The SwapLabs name, logo, credits, and acknowledgement pages are kept in the source package.
