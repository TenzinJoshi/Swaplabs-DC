Simple by design

One code. One recipient. One redemption.

Vouchers are credit transfers with a clear trail. The creator pays when generating the voucher; the recipient receives the exact amount when the code is accepted.

Shareable, not reusableThe server stores only a secure hash of the code and marks it redeemed in the same transaction as the credit transfer.
Made for real membersBoth creating and redeeming require an active signed-in SwapLabs account.
